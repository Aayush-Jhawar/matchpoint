# Matchpoint

Deploy wrapper. The code lives at https://github.com/Aayush-Jhawar/matchpoint and is downloaded
when the Space starts, so restarting the Space picks up the latest commit on `main`.
Set `GEMINI_API_KEY` as a secret in the Space settings to switch on LLM extraction.
